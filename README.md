# 现代决策学课程 · 前置自测系统

基于现代决策学课程体系（5 个模块、15 个单元），为每节课设计的前置自测题库与交互诊断系统。

## 项目特点

1. **真实科学史与经典原型**：全库 45 道题（15 单元 × 3 题）均基于提出该理论或揭示该偏误的真实科学史事件、经典实验或著名原型案例出题，杜绝自编情景导致多概念套用。
2. **选项特征绝对平权**：单题内各选项字数极差严格为 0，彻底清除任何提示性括号与专业术语倾斜，确保测试者凭借认知内容而非语言特征答题。
3. **客观因果与机制判定**：弃用“最该做/最需要留意”等主观程度比较句式，采用客观的机制归因、系统边界与因果推导判定，确保正确项逻辑唯一闭合。
4. **答案均匀分布**：全局 A/B/C/D 分布均匀（A11/B11/C11/D12），同一单元内三题答案字母互不重复。

## 目录结构

- `outputs/`
  - `decision_science_prequiz.json`：结构化前置自测题库（包含题干、选项、答案、考察概念与错因说明）。
  - `decision_science_prequiz.html`：自包含互动自测单页，支持在线答题、单元评分诊断与学习路径建议。
  - `build_quiz.py`：由 JSON 题库生成 HTML 自测页的构建脚本。
  - `_units/`：15 个单元独立优化与审核的源数据和校验归档。
- `.workbuddy/memory/`：项目修订与设计演进记录。

## 使用方法

### 本地运行与浏览
直接在浏览器中打开 `outputs/decision_science_prequiz.html` 即可开始自测。

### 重新构建 HTML
若对题库 JSON 进行了修改，运行以下命令重新生成 HTML：
```bash
python3 outputs/build_quiz.py
```
